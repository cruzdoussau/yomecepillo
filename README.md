# YoMeCepillo.cl

Plataforma web de acompanamiento dental para aprender la tecnica de cepillado,
responder una evaluacion, descubrir el nivel de higiene y marcar progreso diario
con racha.

## Desarrollo

```bash
npm install
npm run dev
```

La app corre por defecto en `http://localhost:3000`. Si ese puerto esta ocupado:

```bash
npm run dev -- -p 3001
```

## Scripts

- `npm run dev`: servidor de desarrollo.
- `npm run build`: build de produccion.
- `npm run lint`: revision con ESLint.

## Stack

- Next.js
- React
- Tailwind CSS
